# Двухслойная микрополосковая антенна круговой поляризации Ка-диапазона (29 ГГц) с апертурной связью

Проект содержит полный цикл проектирования, аналитического расчета и численного электродинамического моделирования микрополосковой антенны круговой поляризации миллиметрового диапазона (центральная частота 29,0 ГГц, Ka-диапазон). Излучатель выполнен по схеме апертурно-связанного резонатора со щелевым возбуждением через крестообразную апертуру в заземляющей пластине и включает дополнительный паразитный резонатор (stacked patch) для расширения рабочей полосы частот.

## Общее описание проекта

Целью разработки является создание компактной печатной антенны диапазона 28,0–30,0 ГГц с круговой поляризацией и расширенной полосой рабочих частот для систем миллиметровой связи, радиолокации и спутниковых каналов Ка-диапазона.

Основные технические особенности архитектуры:
- **Тип структуры**: многослойная микрополосковая антенна с наложенными резонаторами (stacked patch).
- **Метод возбуждения**: электромагнитная апертурная связь через крестообразную щель (cross-slot) в экране с питанием микрополосковой линией.
- **Согласование**: четвертьволновый разомкнутый настроечный шлейф, центрированный непосредственно над апертурным крестом.
- **Формирование круговой поляризации**: срезы противоположных углов (corner truncation) излучающего элемента для расщепления вырожденных мод $TM_{10}$ и $TM_{01}$ в квадратуре ($90^\circ$).
- **Расширение полосы**: второй (паразитный) резонатор над основным патчем, формирующий двухрезонансный частотный отклик.

## Аналитический расчет

Аналитическая часть работы реализована в среде Mathcad ([patch_antenna_analytical_calc.xmcd](calculations/patch_antenna_analytical_calc.xmcd)) и включает синтез микрополоскового тракта и базовых размеров апертуры:

1. **Электрофизические параметры подложки**:
   - Относительная диэлектрическая проницаемость: $\varepsilon_r = 2{,}33$.
   - Толщина диэлектрика: $h = 0{,}254\text{ мм}$ ($10\text{ mil}$).
   - Толщина медной фольги: $t = 35\ \mu\text{m}$.
   - Расчетная полоса частот: $f_1 = 28{,}0\text{ ГГц}$, $f_2 = 30{,}0\text{ ГГц}$, средняя частота $f_0 = 29{,}0\text{ ГГц}$.

2. **Оценка базовых размеров прямоугольного патча**:
   - Теоретическая ширина: $W = \frac{c}{2 f_0} \sqrt{\frac{2}{\varepsilon_r + 1}} \approx 4{,}01\text{ мм}$.
   - Краевое удлинение за счет краевых полей рассеяния: $\Delta L \approx 0{,}129\text{ мм}$.
   - Эффективная полуволновая длина: $L_{\text{eff}} \approx 3{,}13\text{ мм}$.

3. **Синтез апертурного элемента связи (Cross-Slot)**:
   - Ширина плеч крестообразной щели: $W_{\text{cross}} = 1{,}0\text{ мм}$.
   - Длина каждого плеча щели: $L_{1\text{cross}} = L_{2\text{cross}} \approx 1{,}69\text{ мм}$ ($\approx \lambda_g / 4$).

4. **Микрополосковая линия передачи и согласующий шлейф**:
   - Квазистатическая эффективная диэлектрическая проницаемость (по модели Wheeler & Schneider): $\varepsilon_{\text{eff},0} = 1{,}961$.
   - Коррекция частотной дисперсии микрополосковой линии в СВЧ-диапазоне (по модели Kobayashi): $\varepsilon_{\text{eff}}(29\text{ ГГц}) = 1{,}997$.
   - Учет конечной толщины металлизации (Wheeler): поправка $\Delta W_2 \approx 0{,}215\text{ мм}$.
   - Параметры четвертьволнового согласующего шлейфа: длина $L_t = \lambda_g / 4 \approx 1{,}83\text{ мм}$, длина волны в тракте $\lambda_g \approx 7{,}32\text{ мм}$, ширина полоскового проводника $W_t \approx 0{,}54\text{ мм}$ при характеристическом импедансе $Z_0 = 50\ \Omega$.

## 3D-моделирование и оптимизация

Численное электродинамическое моделирование выполнено в CST Studio Suite ([cp_stacked_patch_antenna_29ghz.cst](simulation/cp_stacked_patch_antenna_29ghz.cst)). Процесс оптимизации топологии состоял из следующих последовательных этапов:

1. **Базовая конфигурация одиночного патча**:
   - Создана микрополосковая линия с четвертьволновым настроечным шлейфом, расположенным строго над центром крестообразной апертуры в экране для компенсации реактивной составляющей связи.
2. **Оптимизация КСВН**:
   - Параметрическая коррекция размеров основного резонатора позволила локализовать резонанс вблизи расчетной частоты 29,0 ГГц.
3. **Получение круговой поляризации**:
   - На противоположных углах квадратного резонатора со стороной $2{,}65\text{ мм}$ выполнены диагональные срезы размером $\Delta c = 0{,}35\text{ мм}$ под углом $45^\circ$. Срезы вносят асимметрию, расщепляя вырожденную фундаментальную моду на две ортогональные пространственные компоненты с фазовым сдвигом $90^\circ$.
4. **Расширение полосы с помощью паразитного патча (Stacked Patch)**:
   - В структуру введен второй слой диэлектрика с размещенным сверху паразитным микрополосковым патчем. Связанная система двух резонаторов обеспечивает расширение полосы согласования по уровню $S_{11} < -10\text{ дБ}$ и полосы круговой поляризации по критерию осевого отношения $\text{AR} < 3\text{ дБ}$.
5. **Интеграция коннектора и корпуса**:
   - Смоделирован торцевой высокочастотный разъем SMA (End-Launch) и защитный конструктивный корпус (base + cover).

## Результаты электромагнитного моделирования

### 1. Коэффициент отражения ($S_{11}$)
На частоте 29,0 ГГц коэффициент отражения составляет $S_{11} = -13{,}24\text{ дБ}$. Резонансный минимум достигает $-28{,}0\text{ дБ}$ на частоте 28,5 ГГц. Полоса согласования по критерию $S_{11} \le -10\text{ дБ}$ составляет от 27,2 до 29,8 ГГц (абсолютная полоса 2,6 ГГц, относительная полоса $\approx 9{,}0\%$).

### 2. Коэффициент стоячей волны по напряжению (КСВН / VSWR)
На частоте 29,0 ГГц КСВН составляет $1{,}56$. В полосе частот 27,2–29,8 ГГц значение КСВН не превышает $2{,}0$, опускаясь до минимального значения $1{,}08$ в окрестности 28,5 ГГц.

### 3. Входной импеданс ($Z_{11}$)
На частоте 29,0 ГГц действительная составляющая входного импеданса равна $\mathrm{Re}(Z_{11}) = 32{,}66\ \Omega$, мнимая составляющая составляет $\mathrm{Im}(Z_{11}) = 4{,}92\ \Omega$. Низкое значение реактивной составляющей подтверждает режим параллельного резонанса структуры.

### 4. Осевое отношение (Axial Ratio / Поляризация)
В зенитном направлении ($\theta = 0^\circ$) на частоте 29,0 ГГц осевое отношение составляет $\approx 1{,}0\text{ дБ}$, что существенно ниже общепринятого граничного уровня круговой поляризации $3{,}0\text{ дБ}$. Устойчивый сектор круговой поляризации охватывает рабочий угол места $|\theta| \le 30^\circ$.
