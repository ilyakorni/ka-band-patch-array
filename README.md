# Широкополосная двухслойная микрополосковая антенна круговой поляризации Ка-диапазона (28–30 ГГц) с апертурной связью

Проект содержит расчет, конструкторские данные и численное электродинамическое моделирование широкополосной микрополосковой антенны круговой поляризации миллиметрового диапазона (рабочая полоса 28.0–30.0 ГГц, Ka-диапазон). Излучатель выполнен по схеме апертурно-связанного резонатора со щелевым возбуждением через крестообразную апертуру в заземляющей пластине и включает дополнительный паразитный резонатор (stacked patch) для расширения рабочей полосы частот.

## Общее описание проекта

Целью разработки является создание компактной широкополосной печатной антенны для диапазона 28.0–30.0 ГГц с круговой поляризацией для систем миллиметровой связи, радиолокации и спутниковых каналов Ка-диапазона.

Основные технические особенности архитектуры:

Тип структуры: многослойная микрополосковая антенна с наложенными резонаторами (stacked patch).<br>
Метод возбуждения: электромагнитная апертурная связь через крестообразную щель (cross-slot) в экране с питанием микрополосковой линией.<br>
Согласование: четвертьволновый разомкнутый настроечный шлейф, центрированный непосредственно над апертурным крестом.<br>
Формирование круговой поляризации: срезы противоположных углов (corner truncation) излучающих элементов для расщепления вырожденных мод $TM_{10}$ и $TM_{01}$ в квадратуре ($90^\circ$).<br>
Расширение полосы: второй (паразитный) резонатор над основным патчем, формирующий двухрезонансный частотный отклик в полосе 28.0–30.0 ГГц.<br>
Подавление поверхностных волн: неоднородности в виде отверстий в земляном полигоне вокруг излучателя для отражения волн подложки и ослабления взаимной связи.<br>
Сверхширокополосная круговая поляризация массива: топология подрешётки $2 \times 2$ с последовательным поворотом элементов ($0^\circ, 90^\circ, 180^\circ, 270^\circ$) для взаимной компенсации паразитных мод и расширения полосы осевого отношения.<br>
Стек материалов и конструкция: высокочастотный диэлектрик Rogers RT/duroid 5870 ($h = 0.254$ мм, $\varepsilon_r = 2.33$), медная фольга $t = 35$ мкм (1 oz), плата 90 $\times$ 89 мм с широкими краевыми полями земли для предотвращения краевого ухудшения КСВН.<br>
Электромагнитная изоляция: заземляющий полигон с щелевой апертурной связью обеспечивает защиту антенного тракта от высокочастотных шумов и помех управляющих микросхем (Beamforming ICs / RFIC).

## Аналитический расчет

Аналитическая часть работы реализована в среде Mathcad ([patch_antenna_analytical_calc.xmcd](calculations/patch_antenna_analytical_calc.xmcd)) и включает синтез микрополоскового тракта и базовых размеров апертуры:

### 1. Электрофизические параметры подложки и стек слоев
Материал подложки: армированный фторопласт Rogers RT/duroid 5870.<br>
Относительная диэлектрическая проницаемость: $\varepsilon_r = 2.33$, тангенс угла потерь $\tan\delta = 0.0012$.<br>
Толщина диэлектрических слоев: $h = 0.254$ мм (10 mil).<br>
Толщина проводника (медь): $t = 35$ мкм (1 oz electrodeposited copper).<br>
Рабочий частотный диапазон: $f_1 = 28.0$ ГГц, $f_2 = 30.0$ ГГц, средняя частота $f_0 = 29.0$ ГГц.

### 2. Оценка базовых размеров прямоугольного патча
Теоретическая ширина:
$$W = \frac{c}{2 f_0} \sqrt{\frac{2}{\varepsilon_r + 1}} \approx 4.01\text{ mm}$$
Краевое удлинение за счет краевых полей рассеяния: $\Delta L \approx 0.129$ мм.<br>
Эффективная полуволновая длина: $L_{\text{eff}} \approx 3.13$ мм.

### 3. Синтез апертурного элемента связи (Cross-Slot)
Ширина плеч крестообразной щели: $W_{\text{cross}} = 1.0$ мм.<br>
Длина каждого плеча щели: $L_{1\text{cross}} = L_{2\text{cross}} \approx 1.69$ мм ($\approx \lambda_g / 4$).

### 4. Микрополосковая линия передачи и согласующий шлейф
Квазистатическая эффективная диэлектрическая проницаемость (по модели Wheeler & Schneider): $\varepsilon_{\text{eff},0} = 1.961$.<br>
Коррекция частотной дисперсии микрополосковой линии в СВЧ-диапазоне (по модели Kobayashi): $\varepsilon_{\text{eff}}(29\text{ GHz}) = 1.997$.<br>
Учет конечной толщины металлизации (Wheeler): поправка $\Delta W_2 \approx 0.215$ мм.<br>
Параметры четвертьволнового согласующего шлейфа: длина $L_t = \lambda_g / 4 \approx 1.83$ мм, длина волны в тракте $\lambda_g \approx 7.32$ мм, ширина полоскового проводника $W_t \approx 0.54$ мм при характеристическом импедансе $Z_0 = 50\ \Omega$.

## 3D-моделирование и оптимизация одиночного излучателя

Численное электродинамическое моделирование выполнено в CST Studio Suite ([cp_stacked_patch_antenna_29ghz.cst](simulation/cp_stacked_patch_antenna_29ghz.cst)). Процесс проектирования и оптимизации топологии антенны состоял из следующих последовательных этапов:

### 1. Базовая конфигурация одиночного патча
Смоделирован первичный микрополосковый фидер с четвертьволновым настроечным шлейфом, расположенным непосредственно над центром крестообразной щели связи в экране для компенсации реактивной индуктивной составляющей апертуры.

### 2. Подстройка согласования (КСВН)
Выполнена параметрическая коррекция геометрических размеров основного резонатора для обеспечения оптимального согласования и минимизации коэффициента стоячей волны в рабочей полосе частот.

### 3. Формирование круговой поляризации
На противоположных углах квадратного резонатора со стороной 2.65 мм выполнены диагональные срезы размером $\Delta c = 0.35$ мм под углом $45^\circ$. Данная геометрическая асимметрия расщепляет вырожденную моду на две ортогональные пространственные компоненты с равными амплитудами и фазовым сдвигом $90^\circ$.

### 4. Расширение полосы с помощью паразитного патча (Stacked Patch)
На дополнительной подложке толщиной $h_2 = 0.203$ мм над основным излучателем размещен верхний паразитный микрополосковый резонатор. Первичные геометрические параметры:

Размер квадратного паразитного патча составляет 2.01 мм $\times$ 2.01 мм.<br>
Диагональные срезы углов верхнего патча имеют размер $\Delta c_{\text{top}} = 0.29$ мм под углом $45^\circ$, что обеспечивает согласованную круговую поляризацию на обеих модах.<br>
Образованная связанная двухконтурная резонансная система обеспечивает широкополосную работу в диапазоне 28.0–30.0 ГГц как по согласованию ($S_{11} < -10$ дБ), так и по коэффициенту эллиптичности ($\text{AR} < 3$ дБ).

## Результаты электромагнитного моделирования одиночного элемента

### 1. Коэффициент отражения ($S_{11}$) и граничные частоты полосы пропускания
В широкополосном диапазоне 28.0–30.0 ГГц антенна демонстрирует устойчивое согласование с глубоким резонансным провалом.<br>
На проектной частоте 29.0 ГГц коэффициент отражения составляет $S_{11} = -13.24$ дБ.<br>
Резонансный минимум достигает диапазона от $-21.5$ до $-28.0$ дБ в рабочей полосе.

Первичные граничные частоты согласования по уровню $S_{11} \le -10$ дБ:

Нижняя граница рабочего диапазона: $f_{\text{low}} = 27.938$ ГГц при уровне $S_{11} = -10.28$ дБ.<br>
Верхняя граница рабочего диапазона: $f_{\text{high}} = 29.576$ ГГц при уровне $S_{11} = -10.58$ дБ.<br>
Полоса рабочих частот по уровню -10 дБ составляет $\Delta f = 1.638$ ГГц (диапазон 27.94–29.58 ГГц).

## Подрешётка 2×2 с последовательным фазово-пространственным поворотом

Для кардинального подавления деградации круговой поляризации, вызванной взаимной связью и поверхностными волнами в больших антенных массивах, оптимизированные излучатели скомпонованы в базовую подрешётку $2 \times 2$ по методу последовательного пространственного поворота и фазового сдвига (Sequential Rotation Technique).

### 1. Архитектура и геометрия подрешётки $2 \times 2$
В структуре $2 \times 2$ каждый последующий антенный элемент пространственно повернут относительно предыдущего на $90^\circ$ по кругу ($0^\circ, 90^\circ, 180^\circ, 270^\circ$). Питание элементов осуществляется со сдвигом фазы возбуждения, точно компенсирующим пространственный поворот: $0^\circ, 90^\circ, 180^\circ, 270^\circ$.<br>
Вокруг каждого излучателя сохраняется защитный контур перфораций экрана для локализации поверхностных волн.

Преимущества последовательного поворота:
Взаимная компенсация кросс-поляризационных компонент поля высших порядков.<br>
Взаимное гашение отраженных волн от входов излучателей на сумматоре делителя мощности, улучшающее общее согласование.<br>
Экстремальное расширение полосы частот с высоким качеством круговой поляризации ($\text{AR} < 3$ дБ).

На центральной частоте 29.0 ГГц осевое отношение в зените равно 1.8 дБ с широким сектором поддержания круговой поляризации $|\theta| \le 18^\circ$.<br>
На верхней частоте 30.0 ГГц осевое отношение в зените равно 1.6 дБ (в решётке $8 \times 8$ рабочий сектор схлопывался до $< 2^\circ$), сохраняя устойчивый сектор $|\theta| \le 25^\circ$.

## Финальная оптимизированная решётка 8x8 и фазированное сканирование

Интеграция всех разработанных решений — оптимизированного двухслойного патча, барьеров из отверстий в земляном полигоне и кластеризации с последовательным поворотом элементов — позволила собрать полномасштабную антенную решётку $8 \times 8$ (64 излучателя), полностью подавить паразитную связь поверхностных волн и гарантировать стабильную круговую поляризацию во всем диапазоне частот 28.0–30.0 ГГц.

### 1. Конструктив печатной платы, стек слоев и подавление краевых эффектов
Полноволновой электродинамический расчет выполнен для законченной конструкции многослойной печатной платы:

Материал подложки: СВЧ-ламинат Rogers RT/duroid 5870 с относительной диэлектрической проницаемостью $\varepsilon_r = 2.33$ и тангенсом потерь $\tan\delta = 0.0012$.<br>
Толщина слоев диэлектрика: $h = 0.254$ мм (10 mil).<br>
Материал металлизации: медь толщиной $t = 35$ мкм (1 oz copper).<br>
Физические габариты антенного полотна: 90.00 $\times$ 89.00 мм (до 99 $\times$ 89 мм с учетом монтажных технологических зон).

Широкие краевые поля земли (Ground Margins):
По периметру матрицы излучателей сформированы широкие сплошные поля заземляющего полигона.<br>
Благодаря этому краевые патчи находятся в идентичном электродинамическом окружении с центральными элементами решётки, что исключает краевой эффект искажения импеданса и деградацию КСВН на периферии массива.

Экранирование интегральных микросхем:
Конструкция с апертурной электромагнитной связью через сплошной металлический экран обеспечивает полное радиочастотное экранирование антенного полотна от шумов, гармоник и паразитных наводок микросхем формирования диаграммы направленности (Beamforming ICs / RFIC), монтируемых на противоположной стороне платы.

Резонансные минимумы КСВН достигают 1.0–1.2 в окрестности 28.8 ГГц.<br>
Широкополосное согласование по критерию $\text{КСВН} < 2.0$ гарантированно выдерживается в диапазоне 28.1–29.7 ГГц для каждого из каналов массива.

На частоте 28.0 ГГц осевое отношение в зените составляет 2.1 дБ (в исходной структуре достигало 5.3 дБ с полной потерей круговой поляризации).<br>
На центральной частоте 29.0 ГГц осевое отношение в зените составляет 1.6 дБ (в исходной структуре составляло 3.9 дБ).<br>
На верхней частоте 30.0 ГГц осевое отношение в направлении нормали достигает рекордных 0.7 дБ (в исходной структуре рабочий сектор сужался до $< 2^\circ$).

### 4. Энергетические характеристики и диаграмма направленности
При синфазном сложении полей на частоте 29.0 ГГц решётка демонстрирует высокие показатели направленности:

Коэффициент усиления (Realized Gain): 21.8 dBi (увеличение по сравнению с базовыми 21.3 dBi).<br>
Ширина главного лепестка по уровню половинной мощности (HPBW): $10.0^\circ$.<br>
Уровень боковых лепестков (SLL): $-12.3$ дБ.<br>
Эффективность излучения (Radiation Efficiency): 93.5% ($-0.29$ дБ).<br>
Полная эффективность (Total Efficiency): 86.4% ($-0.63$ дБ).

### 5. Электронное фазированное сканирование луча (Beam Steering)
Для оценки применения антенной матрицы в адаптивных фазированных антенных решётках (ФАР) и спутниковых терминалах промоделировано электронное сканирование главного лепестка при введении прогрессивного фазового сдвига между каналами:

Отклонение луча на $0^\circ$ (нормаль / зенит):<br>
Максимальная напряженность поля: $E_{\text{max}} = 395$ В/м.<br>
Ширина диаграммы направленности по уровню половинной мощности: $\text{HPBW} = 9.4^\circ$.<br>
Уровень боковых лепестков: $\text{SLL} = -5.8$ дБ.<br>
Осевое отношение (Axial Ratio): глубокий минимум $\text{AR} \approx 1.6$ дБ строго по направлению главного луча ($\theta = 0^\circ$).

Отклонение луча на $17^\circ$:<br>
Максимальная напряженность поля: $E_{\text{max}} = 391$ В/м.<br>
Ширина диаграммы направленности по уровню половинной мощности: $\text{HPBW} = 9.9^\circ$.<br>
Уровень боковых лепестков: $\text{SLL} = -5.5$ дБ.<br>
Осевое отношение (Axial Ratio): сектор круговой поляризации ($\text{AR} < 3.0$ дБ) синхронно смещается вслед за лучом, сохраняя чистоту круговой поляризации на $\theta = 17^\circ$.

Отклонение луча на $33^\circ$:<br>
Максимальная напряженность поля: $E_{\text{max}} = 325$ В/м.<br>
Ширина диаграммы направленности по уровню половинной мощности: $\text{HPBW} = 11.7^\circ$.<br>
Уровень боковых лепестков: $\text{SLL} = -6.5$ дБ.<br>
Осевое отношение (Axial Ratio): даже при широкоугольном отклонении луча на $33^\circ$ минимум осевого отношения ($\text{AR} < 3.0$ дБ) точно отслеживает направление максимума излучения, обеспечивая стабильную работу с сигналами круговой поляризации во всем секторе сканирования.
