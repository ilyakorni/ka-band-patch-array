# Широкополосная двухслойная микрополосковая антенна круговой поляризации Ка-диапазона (28–30 ГГц) с апертурной связью

Проект содержит расчет, конструкторские данные и численное электродинамическое моделирование широкополосной микрополосковой антенны круговой поляризации миллиметрового диапазона (рабочая полоса 28,0–30,0 ГГц, Ka-диапазон). Излучатель выполнен по схеме апертурно-связанного резонатора со щелевым возбуждением через крестообразную апертуру в заземляющей пластине и включает дополнительный паразитный резонатор (stacked patch) для расширения рабочей полосы частот.

## Общее описание проекта

Целью разработки является создание компактной широкополосной печатной антенны для диапазона 28,0–30,0 ГГц с круговой поляризацией для систем миллиметровой связи, радиолокации и спутниковых каналов Ка-диапазона.

Основные технические особенности архитектуры:

Тип структуры: многослойная микрополосковая антенна с наложенными резонаторами (stacked patch).
Метод возбуждения: электромагнитная апертурная связь через крестообразную щель (cross-slot) в экране с питанием микрополосковой линией.
Согласование: четвертьволновый разомкнутый настроечный шлейф, центрированный непосредственно над апертурным крестом.
Формирование круговой поляризации: срезы противоположных углов (corner truncation) излучающих элементов для расщепления вырожденных мод $TM_{10}$ и $TM_{01}$ в квадратуре ($90^\circ$).
Расширение полосы: второй (паразитный) резонатор над основным патчем, формирующий двухрезонансный частотный отклик в полосе 28,0–30,0 ГГц.

## Аналитический расчет

Аналитическая часть работы реализована в среде Mathcad ([patch_antenna_analytical_calc.xmcd](calculations/patch_antenna_analytical_calc.xmcd)) и включает синтез микрополоскового тракта и базовых размеров апертуры:

### 1. Электрофизические параметры подложки
Относительная диэлектрическая проницаемость: $\varepsilon_r = 2{,}33$.
Толщина диэлектрика: $h = 0{,}254\text{ мм}$ ($10\text{ mil}$).
Толщина медной фольги: $t = 35\ \mu\text{m}$.
Рабочий частотный диапазон: $f_1 = 28{,}0\text{ ГГц}$, $f_2 = 30{,}0\text{ ГГц}$, средняя частота $f_0 = 29{,}0\text{ ГГц}$.

### 2. Оценка базовых размеров прямоугольного патча
Теоретическая ширина:
$$W = \frac{c}{2 f_0} \sqrt{\frac{2}{\varepsilon_r + 1}} \approx 4{,}01\text{ мм}$$
Краевое удлинение за счет краевых полей рассеяния: $\Delta L \approx 0{,}129\text{ мм}$.
Эффективная полуволновая длина: $L_{\text{eff}} \approx 3{,}13\text{ мм}$.

### 3. Синтез апертурного элемента связи (Cross-Slot)
Ширина плеч крестообразной щели: $W_{\text{cross}} = 1{,}0\text{ мм}$.
Длина каждого плеча щели: $L_{1\text{cross}} = L_{2\text{cross}} \approx 1{,}69\text{ мм}$ ($\approx \lambda_g / 4$).

### 4. Микрополосковая линия передачи и согласующий шлейф
Квазистатическая эффективная диэлектрическая проницаемость (по модели Wheeler & Schneider): $\varepsilon_{\text{eff},0} = 1{,}961$.
Коррекция частотной дисперсии микрополосковой линии в СВЧ-диапазоне (по модели Kobayashi): $\varepsilon_{\text{eff}}(29\text{ ГГц}) = 1{,}997$.
Учет конечной толщины металлизации (Wheeler): поправка $\Delta W_2 \approx 0{,}215\text{ мм}$.
Параметры четвертьволнового согласующего шлейфа: длина $L_t = \lambda_g / 4 \approx 1{,}83\text{ мм}$, длина волны в тракте $\lambda_g \approx 7{,}32\text{ мм}$, ширина полоскового проводника $W_t \approx 0{,}54\text{ мм}$ при характеристическом импедансе $Z_0 = 50\ \Omega$.

## 3D-моделирование и оптимизация

Численное электродинамическое моделирование выполнено в CST Studio Suite ([cp_stacked_patch_antenna_29ghz.cst](simulation/cp_stacked_patch_antenna_29ghz.cst)). Процесс проектирования и оптимизации топологии антенны состоял из следующих последовательных этапов:

### 1. Базовая конфигурация одиночного патча
Смоделирован первичный микрополосковый фидер с четвертьволновым настроечным шлейфом, расположенным непосредственно над центром крестообразной щели связи в экране для компенсации реактивной индуктивной составляющей апертуры.

### 2. Подстройка согласования (КСВН)
Выполнена параметрическая коррекция геометрических размеров основного резонатора для обеспечения оптимального согласования и минимизации коэффициента стоячей волны в рабочей полосе частот.

### 3. Формирование круговой поляризации
На противоположных углах квадратного резонатора со стороной $2{,}65\text{ мм}$ выполнены диагональные срезы размером $\Delta c = 0{,}35\text{ мм}$ под углом $45^\circ$. Данная геометрическая асимметрия расщепляет вырожденную моду на две ортогональные пространственные компоненты с равными амплитудами и фазовым сдвигом $90^\circ$.

### 4. Расширение полосы с помощью паразитного патча (Stacked Patch)
На дополнительной подложке толщиной $h_2 = 0{,}203\text{ мм}$ над основным излучателем размещен верхний паразитный микрополосковый резонатор. Геометрические параметры верхнего патча оптимизированы для синхронизации связанных контуров:
Размер квадратного паразитного патча составляет $2{,}01\text{ мм} \times 2{,}01\text{ мм}$.
Диагональные срезы углов верхнего патча имеют размер $\Delta c_{\text{top}} = 0{,}29\text{ мм}$ под углом $45^\circ$, что обеспечивает согласованную круговую поляризацию на обеих модах.
Образованная связанная двухконтурная резонансная система обеспечивает широкополосную работу в диапазоне 28,0–30,0 ГГц как по согласованию ($S_{11} < -10\text{ дБ}$), так и по коэффициенту эллиптичности ($\text{AR} < 3\text{ дБ}$).

## Результаты электромагнитного моделирования

### 1. Коэффициент отражения ($S_{11}$) и граничные частоты полосы пропускания
В широкополосном диапазоне 28,0–30,0 ГГц антенна демонстрирует устойчивое согласование с глубоким резонансным провалом.
На проектной частоте 29,0 ГГц коэффициент отражения составляет $S_{11} = -13{,}24\text{ дБ}$.
Резонансный минимум достигает $-21{,}5\dots -28{,}0\text{ дБ}$ в полосе.

Точные граничные частоты согласования по стандартному уровню $S_{11} \le -10\text{ дБ}$:
Нижняя граница рабочего диапазона: $f_{\text{low}} = 27{,}938\text{ ГГц}$ при уровне $S_{11} = -10{,}28\text{ дБ}$.
Верхняя граница рабочего диапазона: $f_{\text{high}} = 29{,}576\text{ ГГц}$ при уровне $S_{11} = -10{,}58\text{ дБ}$.
Полоса рабочих частот по уровню $-10\text{ дБ}$ составляет $\Delta f = 1{,}638\text{ ГГц}$ ($27{,}94$–$29{,}58\text{ ГГц}$), что перекрывает целевую часть Ka-диапазона.

На частоте 29,0 ГГц КСВН составляет $1{,}56$. В полосе частот согласования КСВН не превышает $2{,}0$, опускаясь до $1{,}08$ в зоне оптимального импедансного согласования.

### 3. Входной импеданс ($Z_{11}$)
На частоте 29,0 ГГц действительная составляющая входного импеданса равна $\mathrm{Re}(Z_{11}) = 32{,}66\ \Omega$, мнимая составляющая составляет $\mathrm{Im}(Z_{11}) = 4{,}92\ \Omega$. Низкое значение реактивной составляющей подтверждает параллельный резонансный режим связанных контуров.

### 4. Осевое отношение (Axial Ratio / Поляризация)
В зенитном направлении ($\theta = 0^\circ$) на частоте 29,0 ГГц осевое отношение составляет $\approx 1{,}0\text{ дБ}$, что существенно ниже общепринятого граничного уровня круговой поляризации $3{,}0\text{ дБ}$. Устойчивый сектор круговой поляризации охватывает рабочий угол места $|\theta| \le 30^\circ$.
